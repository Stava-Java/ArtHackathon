# Boxing Canvas

First-person cartoon boxing match. Every step, punch, dodge, and parry paints the canvas, while successful combinations build a procedural musical score. Beat El Chupacabra, then save the painting you made during the fight.

Built with React, Vite, Three.js, and Tone.js.

## Run

Needs Node.js 22.13 or newer.

```bash
cd game
npm install
npm run dev
```

Open the URL the terminal prints (usually `http://localhost:5173`), then click **Start**.

## Controls

| Input | Action |
| --- | --- |
| WASD / arrows | Move |
| Mouse | Aim |
| Q | Jab |
| Space / E | Hook |
| R | Stretch punch (hold to charge) |
| F | Parry |
| Shift | Dash / sprint |

## What's in here

The repository keeps only the playable source, runtime assets, and the small Vite/TypeScript configuration needed for local development.
